this app) is kept with PLW's runbook, in the Professional Latino Workers repository:
`docs/kikecode-lifecycle/` (`README.md`, and `KIKECODE-RELEASE.md` for this app's part).

Do not merge or publish this app before that runbook's database and function steps are done: the
editor expects the newer `kike-sites` answers.
